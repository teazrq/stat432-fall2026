# STAT 432 student repository example

This repository demonstrates where to put weekly discussion questions and final homework reports. The files here are examples of the required paths and formats, not completed homework solutions. Replace the example content with your own work before submitting.

| Week | Discussion question | Final homework report |
| --- | --- | --- |
| 01 | `discussion/week-01-question.md` | `homework/week-01/homework-01.html` or `.pdf` |
| 02 | `discussion/week-02-question.md` | `homework/week-02/homework-02.html` or `.pdf` |
| 03 | `discussion/week-03-question.md` | `homework/week-03/homework-03.html` or `.pdf` |
| 04 | `discussion/week-04-question.md` | `homework/week-04/homework-04.html` or `.pdf` |
| 05 | `discussion/week-05-question.md` | `homework/week-05/homework-05.html` or `.pdf` |

Each discussion file begins with five lines of YAML metadata: `---`, `id:`, `title:`, `author:`, and `---`. Use your Illinois NetID in the `id` and `author` fields. Write one question about that week's topic below the metadata. The examples illustrate the format; they are not submissions to copy.

For homework, download the weekly package from the course website and extract it inside `homework/`. The package creates `week-NN/` with the assignment, solution, and any needed data. Render your own final report to a **self-contained HTML** file or PDF with the exact name shown above. The sample HTML pages in this repository illustrate report structure only. The final report must follow the course's 10-page limit.

Commit and push your files to your own `stat432-fall2026` repository. GitHub must show the submitted file at the exact path by the course deadline. See the [discussion guide](https://teazrq.github.io/stat432rpy/guides/week-01/discussion-workflow.html) and [syllabus](https://teazrq.github.io/stat432rpy/syllabus.html) for the current rules and deadlines.
